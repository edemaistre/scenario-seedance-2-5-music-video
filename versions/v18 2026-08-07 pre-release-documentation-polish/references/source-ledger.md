## User-supplied Magnific music-video reference

Source: https://x.com/magnific/status/2085651131326500968

Label: `structural-observation`.

A local frame and scene-boundary study examined the supplied 30.2 second video. It found roughly 29 substantive shots, with a few additional transition states depending on how morph boundaries are counted. The transferable structure is:

- one recurring performer and coherent world
- recurring performance, human-world tableau, kinetic insert, symbolic object, and transition-plate shot families
- motivated transitions through material, occlusion, steam, paint, camera motion, moving props, and vehicles
- cuts clustered around phrases and energy changes rather than a rigid metronomic interval
- one selective high-density passage, contrasted with more readable holds
- a deliberate closing behavior rather than an arbitrary stop

This observation does not establish which model, prompt, edit, reroll count, or post-production step created each frame. It is not a reliability test and is never a visual default. Do not copy its cast, city, wardrobe, palette, monochrome treatment, color accents, fisheye or tiny-planet optics, or genre.

## Claim boundaries

| Claim | Handling |
|---|---|
| Scenario can generate one continuous multi-minute Seedance shot | Unsupported. Plan 4 to 30 second or Auto coverage and assemble against the master. |
| `referenceAudio` becomes the final soundtrack | False. It is conditioning only. Mux the original master once in post. |
| Silent Seedance generation avoids moderation | Prohibited framing. Silence is used for fidelity and deterministic mastering, never moderation evasion. |
| Fast music always requires fast cuts | False. Use phrase, density, texture, tension, and release. Preserve contrast. |
| A slow track should look static | False. It may use evolving composition, scale, light, material, or camera movement without dense cutting. |
| More references guarantee consistency | Unsupported. Use the smallest high-signal role-mapped set. |
| Exact lyrics, logos, labels, or legal copy will render reliably | Unsupported. Composite approved typography and artwork in deterministic post-production. |
| A finished reference proves a default prompt recipe | False. It provides structural hypotheses only. |

## Reusable conclusions

- Analyze the exact master and supplied lyrics before visual design.
- Separate technical beat candidates from manually verified musical events.
- Create three treatments and approve one visual system before video spend.
- Ask for references explicitly, then create a coherent pack in Scenario when they are absent.
- Build complete frame-based coverage and an animatic before generation.
- Use hybrid anchor sequences plus shorter inserts and recovery footage.
- Give each reference one role and exclusions.
- Write prompts around visible timed state changes and exact closing states.
- Generate silent footage, inspect one proof, produce chapter by chapter, and preserve recovery budget.
- Assemble locally and mux the supplied master once.
